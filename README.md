# FAQ Chatbot

## Objective
To develop a chatbot that answers user questions using FAQ matching.

## Libraries Used
- scikit-learn
- nltk
- pandas

## Method
- FAQ collection
- Text preprocessing
- TF-IDF Vectorization
- Cosine Similarity Matching

## How to Run
python faq_chatbot.py

## Sample Output
User: What is NLP?
Bot: NLP stands for Natural Language Processing.
